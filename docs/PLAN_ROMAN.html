Pasos para comprobar la entrega

  1. Seleccionar Eclipse Temurin JDK 21.0.12 en IntelliJ IDEA. Abrir la carpeta raíz que contiene pom.xml.
  2. En pgAdmin, sobre postgres, ejecutar sql/00_crear_base.sql si aún no existe la base.
  3. Conectarse a practicas_profesionales y ejecutar sql/01_academico.sql, sql/02_ejemplos_academicos.sql y sql/03_verificaciones_academicas.sql.
  4. En PowerShell configurar las variables de entorno y ejecutar pruebas y JavaFX:
$env:DB_USER="postgres"
$env:DB_PASSWORD="1234" # solo para laboratorio local
$env:DB_URL="jdbc:postgresql://localhost:5432/practicas_profesionales"
./mvnw.cmd clean test
./mvnw.cmd javafx:run

Comprobar en la app: Carrera → crear/editar; Estudiante → seleccionar carrera, guardar y buscar; Tutor → guardar/actualizar/eliminar. Probar carné y correo duplicado. Abrir FXML con Scene Builder y comprobar la vista.
